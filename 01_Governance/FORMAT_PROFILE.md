# 格式规范（FORMAT_PROFILE）

版本：1.1（2026-10-26）
默认适用：华南理工大学前沿软物质学院《高分子物理实验》课程报告（2026）。
覆盖关系：课程讲义与官方空白模板 > 本规范 > 历史成品。若课程/期刊另有模板，在专属工作流中覆盖本文件。
实现：`05_Tools/build_report_docx.py` 已按本文件设置页面、字体、行距、图注、三线表、页码；`--margins template` 可切换为官方模板 2.54 cm 边距。它不注入官方模板的封面图/占位符；若课程强制按模板，生成后在 Word/WPS 套模板。生成后仍需目检并导出 PDF。

## 2. 默认课程报告版式（必须逐项设置）

### 2.1 页面

| 项目   | 规格                                            |
| ---- | --------------------------------------------- |
| 纸张   | A4，21.0 × 29.7 cm                             |
| 页边距  | 上 2.20 cm；下 2.00 cm；左 2.35 cm；右 2.15 cm；装订线 0 |
| 页眉   | 1.25 cm；页脚 1.25 cm                            |
| 页眉内容 | 左/中：高分子物理实验报告　<实验名称>，9 pt，宋体，细下边框可选           |
| 页脚   | 居中阿拉伯数字页码，9 pt；从正文第 1 页起                      |
| 分栏   | 单栏                                            |

> 官方空白模板四边为 2.54 cm。若课程明确要求“按模板”，以 2.54 cm 覆盖本表；否则用上表（与 DSC/IR 成品一致）。两种选择都要全文统一，不要混用。

### 2.2 字体与字号

| 层级            | 中文字体 | 西文/数字                          | 字号          | 加粗    | 对齐/间距                           |
| ------------- | ---- | ------------------------------ | ----------- | ----- | ------------------------------- |

| 封面副标题（实验名）    | 宋体   | Times New Roman                | 14 pt（四号）   | 否     | 居中；段后 18 pt                     |
| 一级标题 1 引言     | 宋体   | Times New Roman                | 12 pt（小四）   | 是     | 左对齐；段前 12 pt、段后 6 pt；与下段同页      |
| 二级标题 2.1 实验目的 | 宋体   | Times New Roman                | 12 pt（小四）   | 是     | 左对齐；段前 6 pt、段后 3 pt；与下段同页       |
| 三级标题（少用）      | 宋体   | Times New Roman                | 10.5 pt（五号） | 是     | 左对齐；段前 3 pt、段后 0                |
| 正文            | 宋体   | Times New Roman                | 10.5 pt（五号） | 否     | 两端对齐；首行缩进 2 字符；行距 1.5 倍；段前/段后 0 |
| 图注/表注         | 宋体   | Times New Roman                | 9 pt（小五）    | 否     | 居中；单倍行距；图注在图下、表注在表上             |

> 字体必须“三层钉住”：`docDefaults`、所有 `styles.xml` 样式、每个文本 `run`；页眉页脚、表格、题注、文本框也要显式设置。清除 `w:themeFont` 引用，否则 WPS/Word 会回退为等线/Calibri。这是 DSC 交付中实际踩过的坑。

### 2.3 标题编号

* 使用阿拉伯数字，层级用点号：`1`、`1.1`、`1.1.1`；编号与标题文字之间空一格。

* 全文编号连续，不跳号。TGA 成品的 `3.1 → 3.2 → 3.5` 跳号是反例。

* 标题文字不加句号；标题内不使用自动编号与手写编号混排。

* 正文引用标题时写“见 3.2 节”，不写“见下节”。

### 2.4 图

* 图号连续：`图 1`、`图 2`；图号与图题之间空两格或一个全角空格，全文统一。

* 图题格式：`图 1　PE 第一次与第二次升温 DSC 曲线（吸热向上）`；包含样品、条件、关键标注。

* 图题放在图下方，9 pt，居中；图与图题不得跨页分离。

* 图宽默认 14–15 cm，不超过版心宽度（约 16.5 cm）；同一报告内同类图尺寸一致。

* 位图 ≥300 dpi；优先 300 dpi PNG 或可编辑 SVG/EMF。DSC 成品采用 1440×1040、200 dpi，属于已接受的例外，不作为新任务默认。

* 坐标轴标题写“物理量 / 单位”：`温度 T / ℃`、`波数 ν̃ / cm⁻¹`、`浓度 c / (μg·mL⁻¹)`；无量纲量不写单位。

* 四边框完整；主刻度朝内；默认无网格；图例纵向单列；曲线 1–1.5 pt；拟合线用高对比色并单独成系列。

* 图内不留“Series 1”、软件截图、临时箭头、选区框、测量软件界面。

* 显微照片必须有比例尺；同一组照片比例尺一致；不得用裁剪改变结论。

### 2.5 表

* 三线表：顶线 1.5 pt、表头下线 0.75 pt、底线 1.5 pt；无竖线、无内横线。

* 表号与表题在表上方：`表 1　PE 与 PET 各阶段特征转变温度与相变焓汇总`；9 pt，居中。

* 表头写变量与单位；单位统一放在表头（如 `峰温 / ℃`、`ΔH / (J·g⁻¹)`），不要在每格重复。

* 跨页表重复表头；表格不得跨页断行；单元格垂直居中。

* 排除的数据保留在表中，用“是否纳入拟合/备注”列标注；表注说明排除原因。

* 信息表（样品、仪器、条件）与结果表分开；不要把封面信息表计入“表 1”编号，除非全文统一。

### 2.6 公式

* 公式单独成行，居中；编号右对齐：`（1）`、`（2）`。

* 变量斜体，单位正体；首次出现解释符号。

* 拟合方程给形式与本次参数：`A = kc + b`，`k = 0.15104 ± 0.00099`，`b = −0.02100 ± 0.00599`。

* 化学式与上下标用正确格式：`ΔHm`、`J·g⁻¹`、`cm⁻¹`、`¹H NMR`、`DMSO-d₆`。

### 2.7 参考文献

* 顺序编码制，正文用 `[1]` 上标或方括号，全文统一。

* 课程讲义：`[1] 高分子物理实验课程组. 高分子物理实验讲义（2026 版）[Z]. 广州: 华南理工大学前沿软物质学院, 2026.`

* 期刊：作者. 题名[J]. 刊名, 年, 卷(期): 页码. DOI（如可核验）。

* 图书：作者. 书名[M]. 版次. 出版地: 出版社, 年: 页码.

* 只列正文真正引用过的文献；不凭记忆补 DOI、卷期、页码。

* 参考文献 9 pt，悬挂缩进；不把“网络资料”写成无日期、无链接的条目。

## 3. 封面与首页（课程硬性要求）

课程讲义原文：**“实验报告首页请注明班级、姓名、学号、实验内容，如：X 班-李 XX2020XXX-红外光谱法鉴别聚合物。若因 AI 生成报告导致出现姓名漏写/忘写的情况，该次实验报告成绩则评为 0 分。”**

封面/首页至少包含：

```text
高分子物理实验报告
<实验名称>
```

或按课程示例写成一行：

```text
X 班-李XX2020XXX-红外光谱法鉴别聚合物
```

要求：

* 姓名、学号、班级三项缺一不可；不要只在文件属性或页眉里写。

* 实验内容写全称，不用缩写代号。

* 日期写实际实验日期；多次测试写清楚（如 `2026.09.24（PE）；09.22（PET）`）。

* 室温、气压等未记录时写“未记录”，不要编造。

* 分享/上传公开版本时，姓名与学号应打码或删除；本地提交版保留。

## 4. 文件与命名

### 4.1 命名

```text
<实验名称>_<组别>_实验报告.docx
<实验名称>_<组别>_数据与图表.xlsx
<实验名称>_<组别>_Origin脚本.py
<实验名称>_<组别>_交付说明.md
<实验名称>_<组别>_图1_<内容>.png / .svg
```

* 不使用“最终版”“最终版2”“修改前备份”作为交付名；备份放入 `99_Archive/`。

* 同一批文件的实验名称、组别、日期保持一致。

* 工作表名简洁、无非法字符；脚本中的工作表名与文件一致。

### 4.2 必需交付物

| 交付物          | 要求                                     |
| ------------ | -------------------------------------- |
| DOCX 报告      | 可编辑；图已嵌入；封面信息完整；字体显式；页码/图号/表号连续        |
| PDF 预览       | 由 DOCX 实际渲染，不是另存为；逐页检查分页、图注、表格、公式      |
| XLSX 数据与图表   | 原始数据、处理数据、计算/拟合、结果、原生可编辑图表分表；公式保留      |
| Origin 项目/脚本 | 如课程要求；脚本集中参数区；语法检查；注明是否在目标 Origin 版本实跑 |
| 图片源文件        | 300 dpi PNG；可编辑 SVG/EMF（如需要）           |
| 交付说明         | 文件清单、方法、主要结果、排除数据、未记录/待核项、验证范围         |

### 4.3 可编辑性

* XLSX 图表必须是原生 chart 对象，不能只贴 PNG；公式不能全部被“值”替换。

* DOCX 图片必须能“更改图片”；不要把整页做成一张图。

* SVG 文字保持可编辑；不要转曲后声称可编辑。

* Origin 脚本要能在目标版本运行；不能实跑时明确写“仅完成静态语法/兼容性检查”。

## 5. 渲染与验收

1. DOCX 用 Word/WPS 打开，确认不报“文件已损坏”。
2. 导出 PDF，逐页看：封面、分页、孤行、图注、表格跨页、公式、页码。
3. 运行字体审计：`rFonts` 显式率 100%，主题字体引用 0，黑体/等线/Calibri 残留 0（除非规范要求）。
   - 结构审计：`python3 05_Tools/build_report_docx.py --audit report.docx`（检查 zip/XML/媒体/表格/主题字体）。
   - PDF：必须由 Word/WPS 从最终 DOCX 导出；未导出就写“未渲染/未验证”，不得声称已逐页检查。
4. 检查图片：无拉伸变形、无遮挡、无界面截图、比例尺正确、图中文字 ≥7 pt。
5. 检查表：三线表、表头重复、单位、排除项、表注。
6. 检查正文：每个图/表都被引用；无“详见表 1”悬空引用；无模板示例文字；无“TODO/待补”。
7. 检查封面：班级、姓名、学号、实验内容四项齐全。
8. 检查文件名与交付说明一致；交付说明中的页数、图数、表数以最终渲染为准。

## 6. 已验证的格式陷阱（来自本工作区）

| 陷阱                           | 后果               | 处理                               |
| ---------------------------- | ---------------- | -------------------------------- |
| 主题字体引用未清除                    | WPS 回退为等线，标题不像宋体 | 三层显式设置 + XML 审计                  |
| DOCX 包内残留无类型文件 cover_xml.txt | Word 判定文件损坏      | 清理包内非标准 part；重新打包后打开验证           |
| 图片只在外部更新，DOCX 内未替换           | 正文图与最新数据不一致      | 重新生成 DOCX 或逐张“更改图片”，并核对图注        |
| 交付说明页数与实际渲染不符                | 误以为已验收           | 以 PDF 实际页数为准；每次改动后重渲染            |
| 表格跨页丢表头                      | 阅读困难、评审扣分        | 设置“重复标题行”                        |
| 标题编号跳号                       | 结构不完整            | 生成后自动扫描 3.1/3.2/3.5 类跳号          |
| 上标在纯文本抽取中丢失                  | 误判为数值错误          | 检查 Word 实际显示与 vertAlign，不要只看文本导出 |
| 图片被手动裁剪/压缩                   | 细节丢失、比例尺失真       | 保留原图；非破坏裁剪；显微图比例尺同组一致            |

# 科学诚信规范（SCIENTIFIC_INTEGRITY）

版本：1.1（2026-10-26）
适用：所有由 AI 辅助的实验报告、数据处理、图表、论文与综述。
操作化：AI/学生分工、贡献记录与提交闸门见 `01_Governance/HUMAN_IN_THE_LOOP.md`。

## 1. 课程层面的硬约束

《高分子物理实验》2026 讲义明确规定：

- 实验报告须由个人撰写；同组数据可以相同，其他部分不得照抄。
- **禁止完全使用 AI 写实验报告，可适当使用辅助。**
- 报告首页必须注明班级、姓名、学号、实验内容；因 AI 生成导致姓名漏写/忘写，该次成绩记 0 分。

因此本系统的定位是：**AI 做数据整理、计算、绘图、排版、检查和提出修改建议；实验者做实验、判断、署名和对结论负责。** 不得把 AI 生成的整篇报告直接作为个人报告提交。

若课程要求声明 AI 使用情况，按课程要求如实说明使用的环节（如“数据拟合与排版辅助”），不隐瞒、不夸大。

## 2. 不可逾越的红线

1. **不编造实验数据**：不生成不存在的测量值、峰位、温度、分子量、产率、现象。
2. **不编造文献**：不凭记忆补作者、题名、期刊、年份、卷期、页码、DOI；不能核验的条目删除或标注“待核”。
3. **不编造实验条件**：仪器型号、升温速率、溶剂、浓度、狭缝、柱温、流速、进样量等，未记录就写“未记录/待核”。
4. **不伪造验证**：没打开的 PDF、没渲染的 DOCX、没运行的 Origin 脚本，不得声称“已验证/已运行”。
5. **不篡改原始数据**：不覆盖原件；不删除不利结果；不为提高 R² 无依据地删点。
6. **不歪曲图像**：不拼接、不擦除、不改变比例尺、不用美化滤镜掩盖缺陷；显微图必须保留比例尺与原始视场信息。
7. **不把推测写成事实**：机理、异常原因、文献对比必须标明证据强度。
8. **不冒用他人工作**：不把同组他人撰写的段落、往届报告、网络文本改写后当作自己的分析。

## 3. 事实分层与措辞

每条结论标注其证据类型：

| 类型 | 允许的写法 | 禁止的写法 |
|---|---|---|
| 原始观察 | “图 1 中……处出现吸热峰。” | “说明样品一定发生了……” |
| 计算/拟合 | “在 0.5–10 μg·mL⁻¹ 内，A 与 c 线性相关，R²=0.99991。” | “完全符合比尔定律。” |
| 文献结论 | “文献报道 R6G 在乙醇中的 PLQY 约为 0.9。” | 不标来源地写“众所周知……” |
| 理论解释 | “这与 Kasha 规则一致。” | “实验证明了 Kasha 规则。” |
| 推测 | “可能与内滤效应有关；仅凭本组数据不能区分……” | “这是因为内滤效应。” |
| 未确定 | “未记录室温，故只能作相对比较。” | 用默认值补齐后当作实测 |

## 4. 数据完整性

- 原始数据只读保存；处理副本另存；记录每一步脚本、参数、日期。
- 被排除的数据必须：保留在原始表；在处理表加“是否纳入/排除原因”列；在报告 3.x 或 4.x 说明；图中如显示用空心符号并注明。
- 异常值处理先判断原因（仪器饱和、气泡、基线漂移、样品污染、录入错误），再决定排除；不得只按数值大小删点。
- 缺失值不得用均值/拟合值悄悄填补；如必须填补，单列标注方法并讨论影响。
- 单位换算保留中间量；最终数值与单位一起核对。
- 所有正文数值至少能追溯到“原始文件 → 处理表 → 脚本/公式 → 图表/正文”中的一条链。

## 5. 图像与图表诚信

- 图必须由本次真实数据生成；不得用示意图代替实验曲线。
- 同一图内多条曲线使用一致的处理（平滑、归一化、基线扣除）；如处理不同，图注说明。
- 平滑/拟合不得改变峰位与峰数；平滑参数写入方法或图注。
- 不截断坐标轴以夸大差异；非零起点要清晰且不误导。
- 不把不同放大倍率、不同比例尺的显微图并排而不标注。
- 不用 3D、阴影、渐变、装饰性背景掩盖数据。
- 图注中的数值（Tm、Tc、ΔH、R²、n）必须与表、正文、Excel 一致。

## 6. AI 使用的边界

AI 可以：

- 解析讲义、模板、原始数据列含义；
- 编写并运行计算/绘图/排版脚本；
- 生成图表、表格、DOCX/XLSX/Origin 工程；
- 检查单位、编号、引用、字体、分页；
- 提出讨论角度和误差来源，供实验者判断。

AI 不可以：

- 代替实验者判断“这个峰是不是样品峰”；
- 在缺少原始记录时补写实验现象；
- 代替实验者签署诚信声明；
- 把未实际运行的 Origin 脚本说成“已生成 .opju”；
- 把旧实验的数值/结论带入新报告。

## 7. 交付前诚信自检（逐项打勾）

- [ ] 本次报告的每个数值都能指到本次数据文件或脚本输出。
- [ ] 没有把旧报告/范例的样品名、浓度、峰位、方程、结论复制进来；已跑 `05_Tools/check_contamination.sh` 并逐条确认。
- [ ] 未记录的条件写“未记录/待核”，没有编造。
- [ ] 排除的数据仍在表中，并写了原因。
- [ ] 参考文献真实可查；没有凭记忆补 DOI/卷期。
- [ ] 图表由本次数据生成；没有示意图冒充实验曲线。
- [ ] 推测性语句使用了“可能/推测/尚不能确定/需进一步验证”。
- [ ] 没有声称未实际执行的验证。
- [ ] 封面姓名、学号、班级、实验内容齐全。
- [ ] 报告由本人阅读、改写关键段落并承担署名责任；AI 使用符合课程规定。
- [ ] 已填 `HUMAN_IN_THE_LOOP.md` 的学生贡献记录；未把 AI 整篇生成直接提交。

## 8. 不合格判定

出现以下任一情况，直接判定不合格，不用其他维度高分抵消：

- 编造数据、条件、现象或参考文献；
- 伪造“已运行/已渲染/已验证”；
- 抄袭他人报告或把 AI 整篇生成当作个人报告；
- 删除不利结果或篡改原始数据/图像；
- 封面姓名/学号/班级缺失且未在提交前修复（课程规定记 0 分）。

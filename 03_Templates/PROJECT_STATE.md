# 模板：项目状态（PROJECT_STATE）

> 每个项目一份，放在 `07_Projects/<项目>/PROJECT_STATE.md`。每周更新一次，交付前更新。
> 开工前先填 `00_START/INPUT_PACK.md` 与 `00_START/COVER_FIELDS.md`；AI/学生分工见 `01_Governance/HUMAN_IN_THE_LOOP.md`。

| 子任务/实验 | 状态 | 完成度 | 最后更新 | 交付物 | 阻断项 |
|---|---|---|---|---|---|
| | 未开始/进行中/待核/已完成/已归档 | 0–100% | | | |

状态定义：

- 未开始：没有输入或未动工；
- 进行中：有数据/草稿，未验收；
- 待核：AI/脚本已完成，等待人工确认；
- 已完成：通过 `SCORECARD.md` 验收；
- 已归档：被新版替代，移入 `99_Archive/`。

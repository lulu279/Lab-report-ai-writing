# 模板：任务说明（TASK_BRIEF）

> 每个新任务先填本表，再让 AI 执行。复制到 `07_Projects/<项目>/tasks/<日期>_<任务>.md`。
> 开工前先填 `00_START/INPUT_PACK.md` 与 `00_START/COVER_FIELDS.md`；缺关键项就停。

- 交付格式：
- 截止：
- 版本：

## 2. 输入文件与角色
| 文件 | 角色（DATA/FORMAT/CONTENT/WORK） | 用途 | 不可用于 |
|---|---|---|---|
| | | | |

## 3. 数据与条件
- 样品/分组：
- 测试条件：
- 数据列/单位：
- 已知异常/排除：
- 未记录/待核：

## 4. 要求
- 必须包含的章节/图表：
- 模板/格式：

## 使用规则

- 第 2 节的 `DATA` 文件才能提供本次数值；`FORMAT`/`CONTENT` 不得提供数值。
- 第 7 节只列会改变结论/计算/结构/合规的问题；非关键缺失用“未记录/待核”继续。
- 第 8 节必须如实写“未验证”，不得把计划写成已完成。

# 模板：一轮任务指令（ONE_TURN_PROMPTS）

版本：1.2（2026-10-26）
用法：先读 `00_START/START_HERE.md`；复制对应模板，替换 `<...>`；把本系统目录与本次材料一起交给 AI。不要把所有历史文件一次性上传；只给相关规范、工作流和 1 个最相关范例（优先 `04_Examples/full/` 的全文）。本包不含原始数据与旧成品，见 `PACKAGE_MANIFEST.md`。

---

## A. 实验报告：从原始数据到交付

```text
你是我的科研数据处理与实验报告助手。请严格按以下系统执行，不要凭记忆补全，不要沿用旧实验的样品/数值/结论。

【系统目录】
- 冷启动：<系统>/00_START/START_HERE.md、INPUT_PACK.md、COVER_FIELDS.md
- 规范：<系统>/01_Governance/（STYLE_PROFILE、FORMAT_PROFILE、SCIENTIFIC_INTEGRITY、SOURCE_POLICY、HUMAN_IN_THE_LOOP）
- 工作流：<系统>/02_Workflows/EXPERIMENT_REPORT.md → FIRST_DRAFT.md → REVISION_WORKFLOW.md
- 数据/图表/交付：<系统>/02_Workflows/DATA_FIGURE_DELIVERY.md
- 范例：<系统>/04_Examples/（优先 full/ 里 1 份全文；说明选它的理由）
- 模板：<系统>/03_Templates/COURSE_TEMPLATE.docx、DELIVERY_NOTE.md
- 工具：<系统>/05_Tools/RUN_PYTHON.md、build_report_docx.py、docx_text.py、pdf_text.py、FIGURES.md、check_contamination.sh

【本次任务】
- 实验：<实验名称/编号>
- 组别/日期：<组别/日期>
- 讲义：<路径/章节>
- 原始数据：<路径/文件/工作表>
- 报告模板/格式参考：<路径>
- 内容参考：<路径>
- 封面信息：<班级/姓名/学号/实验内容，或 COVER_FIELDS.md 路径>
- 交付格式：DOCX + PDF（Word/WPS 导出）+ XLSX（+ Origin 如要求）
- 截止/特殊要求：<...>
- 已知缺失/待核：<...>
- 课程 AI 政策：<允许辅助/禁止完全 AI 写作/需声明>

【执行顺序】
1. 读 START_HERE 和 INPUT_PACK；缺关键项（讲义/数据/模板/封面四项/单位）就停下来问，不猜。
2. 读规范与工作流；只选 1 个最相关范例（优先全文），说明选它的理由。
3. 建立输入清单：样品、分组、列含义、单位、条件、排除项；区分 DATA / FORMAT / CONTENT / WORK。
4. 原始数据只读备份；先做数据清洗、计算、拟合与合理性检查，再做图、再写报告。图优先由用户在 Origin/Excel 导出 PNG；你没有绘图库时，交数据 + plot_spec（见 FIGURES.md），不要伪造图。
5. 按 FIRST_DRAFT 起草：一句话问题 → 范围/对比轴 → 骨架 → 图/表先行 → 一节一个论点；未算出的数写【待核】；缺图写 FIG_PLACEHOLDER。
6. 按 REVISION_WORKFLOW 做四遍：论证 / 证据 / 段落 / 压缩；不要省压缩遍。
7. 交叉核对图、表、正文、Excel/脚本中的数值与单位；图注也核对。
8. 按 RUN_PYTHON.md 选真实 CPython；用 build_report_docx.py 生成 DOCX（缺封面字段会报错；草稿用 --draft）；运行 --audit（严格模式会因占位符失败）；在 Word/WPS 打开并导出 PDF；未导出就写“未渲染/未验证”。
9. 跑 check_contamination.sh；逐项过 `07_Projects/高分子物理实验2026/SUBMISSION_CHECKLIST.md`；写交付说明与学生贡献记录。

【硬性要求】
- 不编造数据、条件、文献、DOI；缺失写“未记录/待核”。
- 不删除不利结果；排除点保留在表中并说明；不擅自删实际测过的样品，先问用户。
- 不把旧实验数值/样品名带入；每个数字可追溯到本次数据/脚本。
- 不声称未实际执行的验证（如 Origin 未跑就写“仅语法检查”；PDF 未导出就写“未渲染”）。
- 课程禁止完全 AI 写作；你只做辅助；学生必须确认归属/结论、改写关键段落并署名。
- 封面四项缺一即 0 分；不得只写在页眉/文件属性。
- 所有数据表必须用标准三线表（顶/底 1.5 pt、表头线 0.75 pt、无竖线/内横线）；不要用 Excel 全框表、竖线表、斑马纹。
- 不重复询问已明确的信息；只有会改变结论/计算/结构/合规的问题才先问。

【最终回复】
1. 已完成：
2. 核心结果（带单位/范围/n）：
3. 排除/未采用的数据及原因：
4. 交付文件（相对路径）：
5. 实际做过的验证（打开/渲染/运行/语法/审计）：
6. 未验证/待核/需要学生判断的事项：
```

## B. 只做数据处理与图表（不写报告）

```text
请只处理数据与图表，不写报告正文。

输入：
- 原始数据：<路径>
- 数据说明：<路径>
- 目标图：<图号/内容/数量>
- 输出：processed CSV + XLSX（含原生图）+ PNG/SVG
- 规范：<系统>/01_Governance/FORMAT_PROFILE.md、<系统>/02_Workflows/DATA_FIGURE_DELIVERY.md

要求：
1. 先列列含义/单位/异常/排除建议，等我确认后再计算（若不影响结论可先做并标注假设）。
2. 原始数据只读；处理表保留“是否纳入/原因”列。
3. 每张图给数据源、处理参数、图注草稿。
4. 拟合给方程、参数±标准误、R²、n、范围、残差检查。
5. 输出前自检：单位、坐标轴、图例、四边框、遮挡、图注数值。
6. 交付：文件清单 + 关键结果 + 未验证项。
```

## C. 检查/修复已有报告

```text
请按我的规范审查这份已有报告，不要重写全文；先诊断，再给最小修改方案。

文件：
- 报告：<DOCX>
- 数据/图表：<XLSX/脚本>
- 规范：<系统>/01_Governance/、<系统>/02_Workflows/EXPERIMENT_REPORT.md
- 范例：<1 个最相关>

检查清单：
1. 封面：班级/姓名/学号/实验内容是否齐全（课程缺一即 0 分）。
2. 结构：目的/原理/步骤/结果/讨论/思考题/结论是否齐全；编号是否连续。
3. 数据：正文/图注/表/Excel/脚本数值是否一致；单位/有效数字；排除点是否说明。
4. 论证：结论是否超出数据；是否把推测写成事实；误差是否具体。
5. 图表：图号/表号/引用；标准三线表（顶/底 1.5 pt、表头线 0.75 pt、无竖线/内横线）；图注；四边框；图例；遮挡；比例尺。
6. 格式：字体是否显式（宋体/Times）；字号/行距；页边距；页码；分页/孤行。
7. 文件：DOCX 能否打开；PDF 是否最新；XLSX 原生图数量；交付说明是否与实际一致。
8. 污染：是否误用旧范例数值/样品名？跑 `<系统>/05_Tools/check_contamination.sh`。
9. 合规：封面四项、AI 使用边界、学生贡献记录是否齐全？见 `HUMAN_IN_THE_LOOP.md`。

输出：
- P0 提交阻断项（必须改）
- P1 科学/数据问题
- P2 格式/完整性问题
- 每项给：位置（页/节/图表）、证据、最小修改建议
- 不要自动改文件；等我确认后再改。
```

## C2. 初稿→终稿：按写作动作改稿（本版核心）

```text
请把我的初稿改造成“有论点、有取舍、可评分的课程报告”，不要从零重写。
如果没有初稿，先按 <系统>/02_Workflows/FIRST_DRAFT.md 起草，再回到本模板。

输入：
- 初稿：<DOCX/MD>
- 原始数据/图/表：<路径>
- 终稿参考（可选）：<路径；只学结构与取舍，不抄数值>
- 风格规范：<系统>/01_Governance/STYLE_PROFILE.md
- 改稿工作流：<系统>/02_Workflows/REVISION_WORKFLOW.md
- 风格演化案例：<系统>/04_Examples/STYLE_EVOLUTION.md（选 1–2 个同实验案例）

第一步：先给“改稿计划”，不要动正文：
1. 一句话问题；
2. 保留/删除/降为附注的样品与条件；
3. 每个结果节的对比轴；
4. 必须补的证据（数值/反事实/不确定度/对照）；
5. 必须删的无证据结论；
6. 初稿中必须保留的优点（定量不确定性/边界句/完整结论）；
7. 终稿风险（图号/过强结论/数值不一致/错字）。

第二步（我确认后）逐段改：
- 结果段：图/表定位→主现象→关键数值→归属/比较→限制；
- 讨论段：差异→结构/条件→机理两环→边界；
- 误差段：来源→影响参数→方向/量级→改进；
- 结论：目的→3–6 个数值→限制/下一步；
- 标题写结论/问题，不写样品名；
- 压缩背景/步骤/重复表，保留数值/排除理由/不确定度/边界。

第三步：交付前检查：
- 一句话问题能否说清；
- 每节是否有对比轴；
- 每个结论是否有数值/图/文献；
- 排除点是否有反事实；
- 图号/表号/正文/图注/Excel 是否一致；
- 是否还有“证明/完全符合/人为误差/可以看出来”。

输出：改稿计划 + 修改后的全文 + 差异说明（改了什么、为什么、哪些初稿优点保留了）。
```

## D. 科研论文

```text
请按 <期刊> 模板，把我的研究整理成论文。先不要写全文，先做证据矩阵与图表规划。

输入：
- 研究问题/创新点：<...>
- 数据/图：<...>
- 文献：<...>
- 目标期刊/字数/图数：<...>
- 规范：<系统>/02_Workflows/RESEARCH_PAPER.md、01_Governance/

第一步输出：
1. 一句话研究问题与贡献；
2. 证据矩阵（结论→数据/图→文献→强度→反例）；
3. 图表清单（每个图回答什么问题）；
4. 结构大纲；
5. 尚缺的数据/实验/文献。

我确认后再写。不得编造数据/文献；结论不得超出证据；区分已完成/计划中/未验证。
```

## E. 文献综述

```text
请帮我做一篇关于 <主题> 的综述，先建文献表，不要直接写正文。

边界：时间 <...>；数据库 <...>；纳入/排除 <...>；语言 <...>。
输出：
1. 检索式与命中数；
2. 文献表（作者/年/题名/DOI/问题/方法/关键证据/结论/局限）；
3. 按机制/争议/路线分的 3–5 个主题；
4. 每个主题的共同点、分歧、证据强度、缺口；
5. 建议结构。

要求：不编造文献/DOI；每篇真实可查；引用与论断一一对应；不逐篇罗列。
```

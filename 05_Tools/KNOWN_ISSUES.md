# 已知问题与处理（KNOWN_ISSUES）

版本：1.1（2026-10-26）
来源：本工作区实际交付记录、脚本注释、DOCX/XLSX/PDF 核验。
用途：遇到相同现象先查这里；不要重复踩坑。

## A. DOCX / Word / WPS

### A1. 主题字体导致字体回退
- 现象：明明设置宋体，WPS 打开标题变等线/Calibri。
- 原因：样式或 run 引用主题字体（`w:asciiTheme` 等），未显式写 `rFonts`。
- 处理：`docDefaults` + 所有样式 + 每个 run + 页眉页脚/表格/题注三层显式；清除主题引用。
- 验证：解压 DOCX，统计 `rFonts` 与 `themeFont`；目标：显式率 100%、主题引用 0。

### A2. DOCX 报“文件已损坏”
- 现象：Word 打不开，提示损坏。
- 已知原因：包内残留无类型文件 `cover_xml.txt`（DSC 历史版本）。
- 处理：删除非标准 part；重新打包；打开验证。
- 预防：生成后 `zipfile.testzip()` + Word/WPS 打开。

### A3. 内嵌图未更新
- 现象：外部 PNG 已更新，DOCX 里还是旧图；或图注已改、图未改。
- 已知原因：交付说明要求手动“更改图片”，但用户/后续脚本未执行。
- 处理：重新生成 DOCX；或逐张“更改图片”后核对图注/数值。
- 预防：图片更新必须触发 DOCX 重建；交付前逐图核对。

### A4. 页数/图数/表数与交付说明不符
- 现象：DSC 说明 12 页、渲染 9 页；IR 说明 14/17 页、7/10 表。
- 原因：说明手写，文档多次改版。
- 处理：以最终 PDF/ DOCX 统计为准；交付说明由脚本生成或最后更新。
- 预防：交付前跑统计脚本，写“页数：__（渲染日期）”。

### A5. 表格跨页丢表头
- 处理：设置首行“重复标题行”；避免行内跨页断行。
- 验证：PDF 逐页看续表。

### A6. 标题跳号/图号重复
- 已知：TGA `3.1→3.2→3.5`；IR 图号错位（PVA 图注“图6”、正文“图5”；手套也标“图6”）；GPC 图 3 无图注；POM 正文引用图 6 但无图 6。
- 处理：生成后扫描编号；重排并更新所有引用。
- 预防：图/表用自动编号或集中编号表。

### A7. 上标在纯文本抽取中丢失
- 现象：GPC 的 `1.05×10⁵` 被读成 `1.05×105`；误判为数值错误。
- 原因：`w:t` 文本不含上标格式，`vertAlign=superscript` 在 `rPr` 中。
- 处理：检查 Word 实际显示或 `vertAlign`；不要只凭文本导出判断。
- 预防：数值审计同时看格式。

## B. XLSX / Excel

### B1. 原生图表位置不标准
- 现象：统计 `xl/charts/chart*.xml` 为 0，但 Excel 里明明有图。
- 原因：IR 的图放在 `xl/drawings/charts/chart1–7.xml`。
- 处理：统计时同时查 `xl/charts/` 与 `xl/drawings/charts/`。
- 验证：打开 Excel 数图 + 检查 chart part。

### B2. 图表数量与说明不符
- 已知：IR 说明 8 图；XLSX 实际 7 个 chart part（DOCX 另有 8 幅正文图，两者分开统计）；NMR xlsx 0 图。
- 处理：打开数图；补图或改说明；不要把“数据表”称为“图表”。

### B3. 公式被值替换
- 现象：改数据不重算。
- 处理：保留公式；只对最终汇总可值化；交付前用 Excel 重算检查。

### B4. `#REF!`/空引用
- 处理：打开检查；修正范围；图表重新绑定。

## C. Origin

### C1. COM 残留实例导致挂起
- 现象：脚本长时间无输出、无报错。
- 原因：异常中断留下 `Origin64.exe`。
- 处理：任务管理器结束所有 `Origin64.exe`，重跑；一次只跑一个脚本。

### C2. `draw -l` 不落图
- 现象：Origin 2021 中命令不报错，但引线不显示。
- 处理：标注用文本对象；需要引线则手动加。
- 交付说明写明“图内标注为文本对象”。

### C3. 未实际运行却声称已生成 `.opju`
- 处理：只有脚本 → 写“仅语法/兼容性检查”；必须实际打开 `.opju` 才能说“已生成/已验证”。

### C4. 版本不清
- 已知：TGA 有 `TGA第一组.opju`、`.opju.new`、`TGA数据.opju`；UV 有两个 opju。
- 处理：保留一个最终版，其余入 `99_Archive/`；交付说明写文件名/版本/日期。

## D. 数据与文件组织

### D1. 原始数据缺失
- 已知：UV-Vis 原始 CSV 不在工作区；POM 原始照片未单独归档；TGA 无 XLSX/PDF。
- 处理：找回原始文件；找不到则在交付说明写“仅 xlsx/汇总表可复核”，不要假装有原始数据。

### D2. 中间目录混入交付
- 已知：`_work/`、`work/`、`__pycache__`、旧版 DOCX、重复 PDF/模板。
- 处理：交付只放最终文件；中间件入 `99_Archive/` 或删除；保留脚本/原始数据。

### D3. 路径漂移
- 已知：DSC 说明的 `图表PNG/`、IR 说明的 `figures_v2/` 在当前目录不存在。
- 处理：交付说明用相对路径；打包前逐项检查存在性。

### D4. 大文件
- 已知：POM DOCX 10.4 MB（图片未压缩）。
- 处理：压图到 300 dpi/合适尺寸；保留原图另存；不要用低清图替换。

### D5. 重复文件
- 已知：`DSC/高分子物理实验报告_UV-Vis_第一组(2).docx` 与 UV 成品重复；多份课程 PDF/模板副本。
- 处理：保留一份；其余归档；文件名写清用途。

## E. 内容/合规

### E1. 封面缺姓名/学号/班级
- 已知：8/8 不合规（7 份全缺，UV 缺班级）；课程规定可能记 0 分。
- 处理：**最高优先级**；提交前逐份检查首页。

### E2. 结论超出证据/推测写成事实
- 处理：按 `SCIENTIFIC_INTEGRITY.md` 分层；用“可能/推测/尚不能确定”。
- 检查：结论逐句对照证据矩阵。

### E3. 误差分析空泛
- 处理：每条误差写“来源→影响哪个参数/方向→为什么→改进”。
- 反例：“人为误差”“仪器误差”单独出现。

### E4. 课程禁止完全 AI 写作
- 处理：AI 只做辅助；实验者确认/署名；按需声明。
- 不得把 AI 整篇生成直接提交。

## F. 审计/解析陷阱

### F1. 把正文段落误判为图注
- 现象：PL 正文“图 2 比较了……”被正则当成图注。
- 处理：图注需结合样式/位置/短文本判断；不要只按“图 N”开头。

### F2. 把域/文本框内容漏掉
- 处理：解析 `w:t` 时同时查文本框、页眉页脚；封面可能在表格/文本框。

### F3. 页面尺寸混用
- 已知：NMR 用 Letter、GPC/PL 左右 3.17 cm、UV 无衬线。
- 处理：以 `sectPr` 核验；新报告统一 A4/默认边距。

### F4. “PDF 存在”不等于“最新”
- 处理：比对 DOCX/PDF 修改时间、页数、图注；必要时重新导出。

## G. 快速排查顺序

1. 文件能不能打开？（zip/Word/Excel）
2. 封面四项有没有？
3. 页数/图数/表数是否与说明一致？
4. 图/表编号是否连续、正文是否引用？
5. 字体是否显式？主题引用是否为 0？
6. 关键数值在正文/图注/表/Excel 是否一致？
7. 是否有旧实验数值/样品名？
8. 是否声称了未做的验证？

## H. 报告生成器 / 运行环境

### H1. 沙箱 `python3` 跑不了生成器
- 现象：`python3 05_Tools/build_report_docx.py ...` 报 `NotImplementedError: zipfile` 或 `SyntaxError: nonlocal`。
- 原因：Qoder 沙箱的 `python3` 是 Skulpt shim，不是 CPython。
- 处理：用宿主机真实 Python 3.10+（本系统用 qoder_bridge 的 Python 3.14）运行；先 `python3 -c "import zipfile; print('ok')"` 自检。入口见 `05_Tools/RUN_PYTHON.md`。

### H2. 没有 PDF 转换器
- 现象：命令行无 `soffice`/`libreoffice`/`pandoc`/WPS。
- 处理：在 Word/WPS 中打开最终 DOCX，导出 PDF，逐页检查；未导出就写“未渲染/未验证”。

### H3. 没有 python-docx / numpy / matplotlib
- 现象：`import docx` / `numpy` / `matplotlib` 失败；C 扩展 `.so` 可能被拒载。
- 处理：DOCX 用 `build_report_docx.py`（纯标准库）；XLSX 用 `openpyxl`；绘图用 Origin/Excel GUI 或已有 PNG/SVG。不要声称“已用 matplotlib 重跑”。

### H4. 公式不是原生 Word 公式
- 现象：`$$...$$` 生成的是居中斜体文本，不是 OMML。
- 处理：课程要求原生公式时，在 Word/WPS 中手动插入；或在交付说明写“公式为文本排版”。

### H5. 只支持 PNG/JPEG
- 现象：SVG/EMF/TIFF 图片报错。
- 处理：先用 Origin/Excel/图像工具导出 PNG（≥300 dpi）或 JPEG，再嵌入。

### H6. 表题必须紧邻表格
- 现象：`表 1 …` 与表格之间隔了其他段落，生成器会警告“表格缺少表题”。
- 处理：表题后只留空行，不要插入正文；或把表题直接放在表格上一行。

### H7. `--draft` 输出不可提交
- 现象：封面出现 `【待填】`；`--audit` 会报 `FAIL: placeholders remain`。
- 处理：填 `00_START/COVER_FIELDS.md` 后重新生成；不要用草稿提交。`【待核】`/`【缺图】` 同样会让严格审计失败。

### H8. 封面缺项直接报错
- 现象：生成器报“封面字段缺失”。
- 处理：这是故意的。补齐班级/姓名/学号/实验内容；组别/日期可选。不要用 `--draft` 绕过提交要求。

### H9. 历史 DOCX 的 core.xml 里有作者姓名
- 现象：正文没有姓名，但 `docProps/core.xml` 的 `dc:creator`/`cp:lastModifiedBy` 有姓名。
- 处理：收录为范例前跑 `python3 05_Tools/sanitize_docx_meta.py file.docx`；只匿名化元数据，不改正文。
- 注意：课程讲义 PDF 正文可能含教师姓名；仅个人学习使用，公开分享前删除或脱敏。

# 图表从哪来（FIGURES）

版本：1.0（2026-10-26）  
适用：实验报告中的实验曲线、谱图、显微照片、拟合图、示意图。

## 1. 先说边界

当前宿主**没有** matplotlib/numpy/PIL/pureimage 等可用绘图库；AI 不能凭空“画一张实验图”。  
报告生成器只负责把已有 PNG/JPEG 嵌入 DOCX，不负责生成科学图。

所以图表有三种来源：

| 来源 | 谁做 | 适用 | 交付 |
|---|---|---|---|
| A. Origin/Excel/仪器软件导出 | 用户 | 首选；曲线/谱图/拟合图 | 300 dpi PNG（必要时 SVG/EMF） |
| B. 已有图片 | 用户/AI | 显微照片、仪器截图（需清理界面） | PNG/JPEG；显微图带比例尺 |
| C. 数据 + 绘图说明 | AI 出数据，用户出图 | AI 无绘图能力时 | CSV/XLSX + `plot_spec.md` + 用户导出 PNG |

**不允许**：用示意图冒充实验曲线；用旧图代替本次数据；声称“已用 matplotlib 画图”但实际没跑。

## 2. 首选：Origin/Excel 导出

- 图幅接近 4:3 或方形；插入 A4 后文字 ≥7 pt。
- 四边框、刻度朝内、无默认网格；曲线 1–1.5 pt。
- 坐标轴标题：`物理量 / 单位`。
- 图例纵向单列，不遮挡峰/极值/拟合线。
- 导出 PNG ≥300 dpi；需要可编辑时同时给 SVG/EMF/OPJU。注意：`build_report_docx.py` 只嵌 PNG/JPEG；SVG/EMF 作为可编辑源另交，不直接进 DOCX。
- 文件名：`图1_<内容>.png`；与正文图号一致。

## 3. 备用：AI 出数据 + 绘图说明

如果 AI 不能直接出图，交：

```text
figures/
  fig1_data.csv        # x, y1, y2 ...；表头带单位
  fig1_plot_spec.md    # 图型、x/y 轴、范围、刻度、图例、标注、拟合线
  fig1_caption.txt     # 图注草稿
```

`plot_spec.md` 模板：

```text
图号：图 1
图型：线图 / 散点 / 柱状 / 双 Y 轴
数据：fig1_data.csv；x=...；y=...；误差列=...
x 轴：物理量 / 单位；范围=...
y 轴：物理量 / 单位；范围=...
图例：样品 A / 样品 B（纵向单列）
标注：峰位/转变温度/拟合线/排除点
导出：PNG 300 dpi，宽 14–15 cm
```

用户按说明在 Origin/Excel 出图后，把 `fig1.png` 放回 `figures/`，再把报告里的 `FIG_PLACEHOLDER` 换成图片路径。

## 4. 报告里的占位符

在 `report.md` 中可以先写：

```markdown
![图 1　<图注>](FIG_PLACEHOLDER)
```

生成器会渲染成红色“【缺图：FIG_PLACEHOLDER】”提示；`--audit` 会报 `【缺图` 并判为未完成。  
提交前必须换成真实 PNG/JPEG；草稿可以保留，但不得提交。

## 5. 检查清单

- [ ] 每张图来自本次数据/本次样品；
- [ ] 图号连续，正文引用；
- [ ] 图注含样品/条件/关键标注/单位；
- [ ] 坐标轴标题、单位、四边框、图例；
- [ ] 图与图注同页；
- [ ] 显微图有比例尺，同组倍率一致；
- [ ] 没有旧图、示意图、软件界面截图；
- [ ] 没有 `FIG_PLACEHOLDER` / `【缺图`；
- [ ] 交付说明写清“谁出图、用什么软件、是否实跑”。

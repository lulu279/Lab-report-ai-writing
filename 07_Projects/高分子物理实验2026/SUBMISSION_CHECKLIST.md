# 提交前检查清单（SUBMISSION_CHECKLIST）

版本：1.3（2026-10-26）
**定位：只管提交完整性，不管写作质量。** 写作风格看 `01_Governance/STYLE_PROFILE.md`，从零起草看 `02_Workflows/FIRST_DRAFT.md`，改稿看 `02_Workflows/REVISION_WORKFLOW.md`。
用法：每份报告提交前逐项打勾；任一项未过，不提交。可打印本页，一份报告一张。

## 0. 基本信息

```text
实验名称：____________________
组别：第 1 组
姓名：________  学号：__________  班级：________
实验日期：________  提交日期：________
报告文件：____________________________
```

## 1. 封面（课程硬性，缺一可能 0 分）

- [ ] `00_START/COVER_FIELDS.md` 已填
- [ ] 班级已写
- [ ] 姓名已写
- [ ] 学号已写
- [ ] 实验内容/名称已写（全称，不用代号）
- [ ] 组别、实验日期已写
- [ ] 姓名/学号不是只写在页眉/文件属性里
- [ ] 生成器未用 `--draft` 绕过（或已重新生成正式版）
- [ ] 公开分享版已去标识化（本地提交版保留）

## 2. 内容结构（课程要求 5 项）

- [ ] 实验目的
- [ ] 实验原理（公式、符号、适用条件）
- [ ] 实验步骤（按实际操作，关键条件齐全）
- [ ] 实验结果分析与讨论（图/表/数值/机理/误差）
- [ ] 思考题（逐题回答，联系本次数据）
- [ ] 结论（回答目的，不重复步骤）
- [ ] 参考文献（真实、格式统一）
- [ ] 附录（如需：数据文件选择、补充图）

## 3. 数据与计算

- [ ] 原始数据只读备份，未被覆盖
- [ ] 列含义/单位已核对
- [ ] 处理步骤/脚本/参数可追溯
- [ ] 拟合范围、函数、参数±标准误、R²、n 已给
- [ ] 排除点保留在表中，注明原因
- [ ] 正文/图注/表/Excel/脚本数值一致
- [ ] 有效数字与单位统一
- [ ] 至少一种独立复核
- [ ] 未把旧实验数值/样品名带入

## 4. 图表

- [ ] 图号连续，正文每图都被引用
- [ ] 表号连续，正文每表都被引用
- [ ] 图注在图下、表注在表上；含样品/条件/关键标注
- [ ] 坐标轴标题“物理量 / 单位”
- [ ] 四边框、刻度、图例、线宽符合规范
- [ ] 图例不遮挡峰/极值/拟合线/结果表
- [ ] 图片清晰（≥300 dpi 或矢量）；无拉伸/裁切/界面截图
- [ ] 显微图有比例尺，同组倍率一致
- [ ] 标准三线表（顶/底 1.5 pt、表头线 0.75 pt、无竖线/左右边框/其他内横线）；跨页表重复表头；单位在表头；无全框/斑马纹
- [ ] 公式编号/上下标正确（10⁵ 不是 105）

## 5. 版式

- [ ] A4；页边距符合规范
- [ ] 中文宋体、西文/数字 Times New Roman（显式，无主题字体）
- [ ] 主标题 16 pt；节标题 12 pt；正文 10.5 pt；题注 9 pt
- [ ] 正文 1.5 倍行距、首行缩进 2 字符
- [ ] 页码连续；页眉正确
- [ ] 标题编号连续，无跳号
- [ ] 无孤行/图注与图分离/表格断裂
- [ ] 无模板示例文字、TODO、`【待核】`、`【缺图】`、`FIG_PLACEHOLDER`、悬空“见表 X”

## 6. 文件

- [ ] DOCX 能打开，无“文件已损坏”
- [ ] 结构审计：`build_report_docx.py --audit` 通过（媒体/表格/主题字体）
- [ ] PDF 由最终 DOCX 导出，页数与说明一致；未导出则标“未渲染”
- [ ] XLSX 能打开，无 `#REF!`/`#VALUE!`
- [ ] XLSX 原生图表数量与说明一致
- [ ] Origin 工程/脚本：已实跑，或明确写“仅语法检查”
- [ ] 图片源文件（PNG/SVG）齐全
- [ ] 文件命名规范，无“最终版/副本”
- [ ] 交付说明的文件清单与实际一致
- [ ] 旧版/中间件已归档，不在交付目录

## 7. 诚信与合规

- [ ] 没有编造数据/条件/现象/文献/DOI
- [ ] 没有伪造“已运行/已渲染/已验证”
- [ ] 没有删除不利结果/篡改原始数据/图像
- [ ] 推测使用“可能/推测/尚不能确定”
- [ ] 结论不超出证据
- [ ] 已跑 `check_contamination.sh`，命中项逐条确认
- [ ] 学生贡献记录已填（`HUMAN_IN_THE_LOOP.md`）
- [ ] 报告由本人阅读、改写关键段落并署名
- [ ] AI 使用符合课程规定；如需声明已声明
- [ ] 没有把 AI 整篇生成当作个人报告

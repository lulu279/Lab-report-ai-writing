# 从压缩包到第一次可运行演示

1. 在 Windows 电脑上安装 Python 3.11 或 3.12，解压源码 ZIP。
2. 用 PowerShell 打开源码目录，执行：

   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   python -m pytest -q
   ```

3. 运行无需 AI 的数据到 Word 演示：

   ```powershell
   python -m research_engine.cli --data examples/synthetic_dsc.csv --config examples/synthetic_config.json --out runs
   ```

4. 启动网页操作：

   ```powershell
   python -m streamlit run app.py
   ```

   上传 `examples/synthetic_dsc.csv` 与 `examples/synthetic_config.json`，点击“运行数据分析并生成 DOCX 草稿”。

5. 查看 `validation.json` 的 `numerical_status`，检查 DOCX 是否明确写明“合成测试数据”。通过后再按 `docs/IMPLEMENTATION_PLAN.md` 和 `docs/ASSET_AUDIT.md` 补充真实原始数据。

提醒：演示数据由程序生成，**不是 PE/PET 的真实 DSC 仪器数据**。现在的系统只能验证工程框架，不能替代原始实验数据复现。

# 工作流：数据、图表与交付物（DATA_FIGURE_DELIVERY）

版本：1.0（2026-10-25）
适用：实验数据的整理、拟合、科学绘图、XLSX/DOCX/Origin 交付与验收。
上游：`EXPERIMENT_REPORT.md`；格式细节：`01_Governance/FORMAT_PROFILE.md`。

## 1. 数据工作簿（XLSX）结构

推荐工作表顺序：

```text
说明            # 任务、数据来源、列含义、单位、排除规则、版本
原始数据        # 仪器导出原样，只读区
处理数据        # 清洗/换算/分段，标注是否纳入拟合
计算/拟合       # 公式、参数、残差、R²、n
结果汇总        # 最终数值，供正文/图表引用
图1…图N         # 每图一个工作表：数据区 + 原生图表
```

要求：

- 原始与处理后分区；原始区不覆盖。
- 每列表头写变量与单位；不要用 `Column1`。
- 计算尽量保留公式；用户改数据后能重算。
- 拟合表包含：方程、斜率/参数±标准误、截距、R²、调整 R²、n、范围、排除点。
- 图表为原生 chart 对象，数据区域与图表链接；不能只贴 PNG。
- 三线表：顶/底 1.5 pt、表头线 0.75 pt；无竖线；外框可按要求加粗。
- 工作表名简洁；与脚本、报告中的名称一致。
- 交付前打开检查：无 `#REF!`、`#VALUE!`、空引用、错误图例、错误范围。

## 2. 科学绘图

### 2.1 通用

- 数据来源唯一：图必须由本次处理表生成；脚本中不写死旧数值。
- 图幅接近方形或 4:3；插入 A4 后文字 ≥7 pt。
- 坐标轴标题：`物理量 / 单位`；变量斜体、单位正体。
- 四边框完整；默认无网格；主刻度朝内；刻度不过密。
- 同一报告内字体、字号、线宽、图例风格统一。
- 多系列颜色可区分且适合打印：蓝、绿、橙、灰、紫；必要时黑/红。
- 实验数据与拟合线区分：数据黑色/系列色，拟合红色或高对比色；拟合线单独系列。
- 图例纵向单列，不遮挡峰/极值/拟合线/结果表；名称用真实样品名。
- 数据点密集时光谱只画线；Origin 可编辑版可用点线图（同色、1 pt）。
- 不截断坐标轴夸大差异；非零起点要清晰。
- 图中不留软件截图、选区、箭头、`Series 1`、临时文字。

### 2.2 线宽与边框（默认）

| 元素 | 目标 |
|---|---|
| 图框四边 | 3 pt 黑色 |
| 数据曲线 | 1 pt |
| 拟合线 | 1 pt，红色/高对比 |
| 坐标轴刻度 | 与边框一致；朝内 |
| 图例框 | 黑色细线或无边框 |

> IR 成品使用 1.5 pt 曲线并已验收；新任务默认 1 pt，若参考 IR 版式则全图统一 1.5 pt，不混用。

### 2.3 实验类型要点

- **光谱（UV-Vis/PL/IR）**：横轴方向按惯例（IR 4000→400 cm⁻¹）；基线/空白说明；归一化方式写图注；饱和/截顶区不画拟合线。
- **热分析（DSC/TGA）**：吸热方向明确（DSC 吸热向上/向下只选一种）；TGA 双 Y 轴（TG 左、DTG 右）；切线/基线画法在图注说明；ΔH 阴影区标注。
- **GPC**：淋洗曲线 + 积分区间 + 基线；标定曲线给方程/R²；微分/累积分布分开；轴单位 `lg M`、`dw/d(lg M)`。
- **NMR**：横轴 ppm 反向；标峰、积分、多重峰；溶剂峰标注；局部放大图给放大区间。
- **显微（POM）**：比例尺；同组放大倍率一致；测量线过球晶中心；不擦除背景缺陷；必要时给原始视场与标注版两图。

## 3. DOCX 生成

### 3.1 程序化生成

- 优先用模板 + 程序写入；不要手工拼接多个 DOCX。
- 字体：`docDefaults` + 样式 + 每个 run 三层设置；清除主题字体。
- 标题：用真实标题样式或统一直接格式；生成后检查大纲。
- 图：按版心宽度等比缩放；图注与图同段组/同页。
- 表：三线表；表头重复；单元格垂直居中；数字右对齐/居中对齐统一。
- 公式：OMML 或域；避免图片公式；编号右对齐。
- 参考文献：悬挂缩进；正文引用与条目一一对应。
- 页码：页脚域；封面是否计页码按模板。

### 3.2 生成后必做

1. 打开 DOCX（Word/WPS）确认不报损坏。
2. 导出 PDF；逐页检查分页、孤行、图注、表格跨页、公式、页码。
3. 统计实际页数、图数、表数、字数；写入交付说明。
4. 字体审计：`rFonts` 显式率、主题引用数、异常字体数。
5. 图片审计：数量、尺寸、DPI、是否重复、是否与图注匹配。
6. 引用审计：每个图/表在正文出现；无悬空“见表 X”。
7. 封面审计：班级/姓名/学号/实验内容。

## 4. Origin 交付

### 4.1 脚本要求

- 以目标 Origin 版本的内嵌 Python 与 `originpro` 版本为准；不假设新接口。
- 优先基础接口：`op.new_book`、`worksheet.from_list`、`op.new_graph`、`layer.add_plot`、`plot.set_int/set_float`、`layer.set_int/set_float`、`layer.label("Legend")`。
- 路径转 `str(path)`；不把 `WindowsPath` 直接传给旧 pandas。
- 可能不支持的格式属性用 `try/except` 包裹；美化失败也要完成导入、建表、建图、拟合、保存。
- 集中参数区：输入/输出文件名、是否新建、是否保存、颜色、线宽、坐标范围、符号大小。
- 运行后打印：输出位置、拟合方程、主要参数、R²、最终结果。
- 交付前至少 `python -m py_compile`；不能实跑时明确写“仅静态检查，需在目标 Origin 验证”。

### 4.2 已知环境问题（来自 IR 交付）

- `originpro` 通过 COM 启动隐藏的 `Origin64.exe`；异常中断会残留实例，后续自动化挂起（无输出、无报错）。处理：任务管理器结束所有 `Origin64.exe` 后重跑。
- Origin 2021 的 `draw -l` 可能不落图（不报错也不画线）；标注改用文本对象，或手动加引线。
- 一次只跑一个 Origin 自动化脚本；结束确认进程退出再跑下一个。
- 交付的 `.opju` 必须实际生成并打开验证；仅有脚本不能声称“已生成工程”。

### 4.3 可编辑性分级

| 级别 | 交付 |
|---|---|
| A | 原生 `.opju` + 数据工作簿 + 图页，可在 Origin 改数据/样式 |
| B | 脚本可重建 `.opju`，但未在目标版本实跑 |
| C | 只有 PNG/SVG，不可在 Origin 中改数据 |
| D | 只有 DOCX 内嵌位图 |

交付说明必须写明级别；C/D 不得称为“Origin 可编辑”。

## 5. 交付清单与一致性校验

### 5.1 清单模板

```text
交付版本/日期：
1. DOCX：
2. PDF：
3. XLSX：
4. Origin：
5. 图片源文件：
6. 脚本：
7. 原始数据：
8. 交付说明：
验证：打开/渲染/运行/语法检查/未验证项
```

### 5.2 自动校验项

- 文件存在且非空；扩展名与内容匹配（DOCX/XLSX 是 zip；PNG 头正确）。
- DOCX 内图片数 ≥ 正文图数；每张图有图注；图注编号连续。
- XLSX 原生 chart 数 ≥ 交付说明声称数；无 `#REF!`。
- 交付说明中的页数/图数/表数/图表数与实际统计一致。
- 文件名与交付说明一致；无“最终版/副本”。
- 封面四项信息齐全。

### 5.3 人工校验项

- 图是否被拉伸/裁切/遮挡；图中文字是否可读。
- 表是否跨页断行；表头是否重复。
- 公式上下标是否正确显示。
- 正文结论是否超出数据。
- 是否还有旧实验的数值/样品名。

## 6. 常见错误

| 错误 | 后果 | 预防 |
|---|---|---|
| 只交 PNG，不交数据 | 无法复核 | 每图对应工作表/CSV |
| XLSX 图表是图片 | 不能改数据/样式 | 用原生 chart；检查 `xl/charts` |
| 公式全被值替换 | 不能重算 | 保留公式；只对最终汇总可值化 |
| 图注数值与表不一致 | 评审直接扣分 | 图注纳入核对表 |
| 交付说明沿用旧版 | 页数/图数错误 | 每次从最终文件重新统计 |
| 字体主题引用 | WPS 回退 | 三层显式 + 审计 |
| DOCX 内图未替换 | 图文不符 | 重新生成或逐张替换并核对 |
| 只做语法检查就说“已运行” | 诚信问题 | 明确写“未实跑” |

## 7. 验收命令/检查示例

```bash
# DOCX/XLSX 是否为有效 zip
python3 -c "import zipfile; zipfile.ZipFile('report.docx').testzip()"

# DOCX 内图片数、图表数
python3 - <<'EOF'
import zipfile
z=zipfile.ZipFile('report.docx')
print(len([n for n in z.namelist() if n.startswith('word/media/')]))
EOF

# XLSX 原生图表数（含 xl/charts 与 xl/drawings/charts 两种存放）
python3 - <<'EOF'
import zipfile
z=zipfile.ZipFile('data.xlsx')
print([n for n in z.namelist() if n.startswith(('xl/charts/','xl/drawings/charts/'))])
EOF
```

最终以打开/渲染结果为准，不以脚本“无报错”代替人工目检。

# 任务输入包（INPUT_PACK）

> 每个新报告先填本表。缺关键项时停下来问用户，不要用默认值补齐。

## 1. 基本信息

```text
课程/项目：
实验名称与编号：
组别：
实验日期：
提交截止：
交付格式：DOCX / PDF / XLSX / Origin（按课程要求删减）
课程是否允许 AI 辅助：
是否需要 AI 使用声明：
```

## 3. 数据核对

```text

```

## 4. 写作要求

```text
必须包含：目的 / 原理 / 步骤 / 结果分析与讨论 / 思考题（课程五项）
可选：摘要 / 关键词 / 参考文献 / 附录 / 数据处理
图表数量与类型：
参考文献要求：
命名要求：
页数/字数限制：
```

## 5. 最低可行输入（时间不够时）

至少要有：

1. 讲义中对应实验的目的、原理、步骤、思考题；
2. 本次原始数据及列/单位说明；
3. 封面四项；
4. 课程模板或明确的版式要求。

缺其中任何一项，不要开始写正文；先问。

## 6. 停止提问清单

- 样品是什么、测了什么条件、峰/转变怎么归属？
- 数据列/单位/拟合范围/排除规则是什么？
- 交付格式、模板、是否要 Origin？
- 课程是否允许 AI、是否需要声明、封面信息？

非关键缺失（室温、气压、无关外观）可以继续，但必须写“未记录/待核”。

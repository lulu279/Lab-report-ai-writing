# 封面字段（COVER_FIELDS）

> 课程硬性要求：封面/首页必须注明**班级、姓名、学号、实验内容**；缺一可能记 0 分。
> 本表由用户填写，AI 不得编造，也不得只写在页眉或文件属性里。

## 1. 必填（课程四项）

```text
实验内容（全称，不用代号）：
班级：
姓名：
学号：
```

## 2. 建议填写

```text
组别：
实验日期：
提交日期：
报告文件名：
```

## 3. 封面写法

按课程示例可写成一行：

```text
X 班-李XX2020XXX-红外光谱法鉴别聚合物
```

也可以分行：

```text
高分子物理实验报告
红外光谱法鉴别聚合物
班级：X 班
姓名：李XX
学号：2020XXX
组别：第 1 组
实验日期：2026.09.22
```

## 4. 规则

- 四项缺一不可；不确定就停下来问，不要填“待定/XXX”。
- 实验内容写全称；不要只写“实验二”。
- 日期写实际实验日期；多次测试写清楚（如 `2026.09.24（PE）；09.22（PET）`）。
- 室温、气压未记录时写“未记录”，不要编造。
- 公开分享版去掉姓名/学号/班级；本地提交版保留。
- `build_report_docx.py` 检查的是 `report.md` 的 front matter，不是直接读本表；填完本表后，把四项抄进 front matter。缺项会报错；`--draft` 只生成草稿，不得作为提交版。

## 5. 交付前复核

- [ ] 封面四项齐全
- [ ] 姓名/学号不是只在页眉/文件属性
- [ ] 实验名称是全称
- [ ] 组别/日期与本次实验一致
- [ ] 公开版已去标识化

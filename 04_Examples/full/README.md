# 全文范例（full/）

两份历史范例的完整 DOCX + 机器转换 Markdown。只学结构、图位、表格字段与写法；**不要复制样品、数值、结论**。

## 1. IR_GOLD_FULL

- 来源：`IR光谱/FTIR_第一组_实验报告.docx`（历史工作区，包外）。
- 版式：宋体+Times、A4、10.5 pt/1.5 倍、三线表、多图（约 8 幅）、5 表。
- 可学：多图组织（总览→单样品→对比）、峰归属三列法、干扰/饱和边界、鉴别多重证据。
- 不要学：图号错位/重号（PVA/手套）、PAN/PVA“证明含杂质”的过强结论。
- 文件：`IR_GOLD_FULL.docx`（看版式）、`IR_GOLD_FULL.md`（看全文文字；图片未转换）。

## 2. GPC_SILVER_FULL

- 来源：`GPC/GPC_实验报告.docx`（历史工作区，包外）。
- 版式：A4、9 pt、左右 3.17 cm（**不符合**默认格式，只学内容）。
- 可学：淋洗曲线→基线/积分→切片→标定→Mn/Mw/Mz/d 的完整数据链；低分子量峰的审慎讨论；结论回分离原理。
- 不要学：9 pt/3.17 cm、“应该为为”、图 3 无图注。
- 文件：`GPC_SILVER_FULL.docx`（看数据链）、`GPC_SILVER_FULL.md`（看全文文字；图片未转换）。

## 3. 使用规则

- 每个任务只选 1 份；不要一次读两份。
- 范例里的数值是旧数据；交付前跑 `05_Tools/check_contamination.sh`。
- Markdown 是机器转换（`05_Tools/docx_text.py`），版式/图片/公式以 DOCX 为准。
- 两份范例均无姓名/学号/班级；如后续加入含 PII 的范文，先去标识化。

## 1.1 先读：全文范例 + 风格演化

- `full/IR_GOLD_FULL.docx/.md`：版式、图位、峰归属表、多图组织。**优先看 DOCX**，MD 只用于检索。
- `full/GPC_SILVER_FULL.docx/.md`：淋洗曲线→基线/积分→标定→Mn/Mw/Mz/d 的完整数据链。
- `STYLE_EVOLUTION.md`：6 组初稿→终稿的逐段对照（UV、NMR、DSC、IR、PL、GPC），回答“终稿高明在哪里”。

每个新任务只选 **1 份**全文或卡片；不要一次读全部。全文范例也含旧数据/旧结论，只学结构与写法，不学数值。

选择规则补充：

- 想学“删无关内容/补反事实”：看 UV 案例。
- 想学“占位符→实测证据/机理解释”：看 NMR 案例。
- 想学“数据选择/课程报告化”：看 DSC 案例。
- 想学“指纹区方法论/饱和边界”：看 IR 案例。
- 想学“软件值 vs 复算值”：看 PL 案例。
- 想学“结论回原理”：看 GPC/TGA 案例。

## 2. 选择规则

每个新任务只选 **1 个**范例（最多 2 个）：

- 写整篇/版式/多图/峰归属：IR 全文（`full/IR_GOLD_FULL.docx`）；
- 写数据链/分子量：GPC 全文（`full/GPC_SILVER_FULL.docx`）；
- 写结构/拟合/讨论：UV-Vis 或 DSC 卡片；
- 写 TG/DTG：TGA 卡片；
- 只学某一段（误差/QY）：PL 要点；
- 只学谱图归属/图像描述：NMR/POM 要点。

不要让 AI 一次读全部范例；不要把范例中的样品名、数值、结论带入新报告。交付前跑 `05_Tools/check_contamination.sh`。

## 3. 范例的“可迁移/不可迁移”总表

| 可迁移 | 不可迁移 |
|---|---|
| 章节推进方式、论证顺序 | 具体样品、浓度、峰位、温度、分子量 |
| 图表类型与版式 | 坐标范围、颜色顺序、图例位置（需按数据重选） |
| 拟合报告字段 | 拟合方程、斜率、R²、n |
| 误差分析角度 | 具体误差数值、结论 |
| 三线表、字体、图注格式 | 特殊版式例外（UV-Vis 无衬线、NMR Letter） |
| 交付包结构 | 旧版遗留问题（图号重复、标题跳号、错别字） |

## 4. 备用范例要点（未单独建卡）

### PL（光致荧光）
- 强项：QY 软件值 36.04% 与复算 18.3%–21.4% 的差异被如实讨论；内滤/再吸收、积分窗口、信噪比逐条分析；结论区分 Kasha 规则与强度变化。
- 可学：把“不确定度”写进结果，不只写一个漂亮数字。
- 不可学：具体 QY 值、积分窗口、样品浓度。
- 已知问题：封面信息缺失；xlsx 有 7 张原生图，docx 6 图；无 PDF 以外的原始图源目录。

### NMR（核磁）
- 强项：8 张谱的相位/基线/定标/积分流程；A/B 未知物鉴别用“芳香区 vs 脂肪区 + 可交换氢 + 溶解度”多重证据；溶剂效应量化（0.18/0.30 ppm）。
- 可学：鉴别结论用证据链，不靠单一峰。
- 不可学：具体 δ 值、积分、样品结论。
- 已知问题：封面信息缺失；xlsx 无原生图表；表号从“表 2”开始；docx 8 图 1 表。

### POM（偏光显微镜）
- 强项：PP 球晶黑十字、PEG 熔融-结晶序列、PHB 细晶；比例尺与像素换算；图像测量线过中心。
- 可学：图像描述与定量测量结合。
- 不可学：具体直径、放大倍率、视场。
- 已知问题：封面信息缺失；docx 10.4 MB（图片未压缩）；正文引用“图 6”但只有图 1–5 图注；无汇总表；原始照片未单独归档。

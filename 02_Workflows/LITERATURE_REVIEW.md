# 工作流：文献综述（LITERATURE_REVIEW）

版本：1.0（2026-10-25）
适用：课程综述、开题综述、论文引言、方法学比较。
目标：按机制/争议/研究路线组织证据，而不是逐篇摘要。

## 1. 先定边界

```text
主题：
时间范围：
数据库/来源：
检索式（关键词 + 布尔逻辑）：
纳入标准：
排除标准：
语言：
最终篇数：
```

没有边界的综述会变成“文献堆”。先写检索式，再检索。

## 2. 文献表（先建表，后写作）

| ID | 作者/年份 | 题名 | 来源/DOI | 研究问题 | 方法/样品 | 关键证据 | 结论 | 局限 | 与本文关系 |
|---|---|---|---|---|---|---|---|---|---|
| S1 | | | | | | | | | 支持/反驳/背景 |

要求：

- 每篇至少读摘要 + 图表 + 结论；关键文献读方法。
- DOI/卷期/页码来自原文，不凭记忆。
- “关键证据”写具体数值/现象，不写“效果很好”。
- “局限”写样品、方法、统计、外推范围。

## 3. 组织方式（选一种主逻辑）

- **按机制**：同一现象的不同解释路径。
- **按争议**：A 说 X，B 说 Y，证据差异在哪。
- **按研究路线**：方法演进/材料体系演进。
- **按问题链**：是什么 → 为什么 → 怎么调控 → 还有什么没解决。

不要按“第一篇……第二篇……”罗列。每一段至少比较 2 篇。

## 4. 证据综合

对每个论点：

1. 共同结论是什么？多少篇支持？
2. 分歧在哪？样品、条件、方法、数据处理？
3. 证据强度：体外/体内、单次/重复、统计/定性。
4. 是否存在发表偏倚、选择性报告？
5. 还缺什么实验/数据？

写作用语：

- “多数研究支持……，但……条件下出现相反结果 [1,2]。”
- “两项研究的差异可能来自……，而非……本身。”
- “目前尚缺乏……的直接证据。”

## 5. 引用与论断一一对应

- 一个句子一个主论断；句末引用支撑该论断的文献。
- 不用一篇综述支撑多个具体数值。
- 不用“众所周知”“大量研究表明”代替引用。
- 引用二手文献时尽量回溯原始文献。

## 6. 结构模板

```text
摘要（150–250 字）
1 引言：问题重要性 + 已有综述的缺口 + 本文范围
2 概念/机制框架
3 研究进展（按机制/争议/路线分节）
4 比较与综合（条件、证据、解释）
5 争议与不足
6 结论与展望
参考文献
```

## 7. 质量检查

- [ ] 检索式、时间范围、纳入/排除标准写明。
- [ ] 文献表完整，DOI/来源可查。
- [ ] 每节有综合比较，不是逐篇摘要。
- [ ] 争议与证据不足写明。
- [ ] 引用与论断一一对应。
- [ ] 没有用本次未读的文献凑数。
- [ ] 没有把实验报告的结果当文献结论。
- [ ] 参考文献格式统一。

## 8. 交付

- DOCX/PDF（按课程/期刊模板）；
- 文献表（XLSX/CSV，含 DOI）；
- 检索记录（数据库、检索式、日期、命中数）；
- 如需，PRISMA 流程图（系统综述）。

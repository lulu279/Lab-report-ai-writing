版本：1.2（2026-10-26）  
适用：没有初稿，只有讲义、原始数据、模板和封面信息。  
上游：`00_START/INPUT_PACK.md`、`02_Workflows/EXPERIMENT_REPORT.md` 第 1–5 步。  
下游：`02_Workflows/REVISION_WORKFLOW.md` 四遍改稿。

> 本文件只解决一件事：**第一稿怎么从证据长出来**，而不是从模板腔里挤出来。

## 0. 先确认三件事

1. **一句话问题**：在______条件下，______样品的______性质如何？与______相比？为什么？
2. **范围**：哪些样品/条件回答这个问题？哪些不回答？不回答的先问用户能不能删，不要擅自删。
3. **对比轴**：前/后、A/B、条件 1/2、线性区/超范围、已知/未知。每个结果节至少一条。

三件事写不出来，不要开始写正文；回到 `INPUT_PACK` 补材料。

## 1. 先搭骨架，再填字

推荐骨架（课程五项不能少；摘要/参考文献/附录按需）：

```text
封面（COVER_FIELDS 四项）
摘要（可选，150–250 字）
1 引言
2 实验部分
  2.1 实验目的
  2.2 实验原理
  2.3 仪器与样品
  2.4 实验步骤
  2.5 数据处理（可选）
3 数据与结果
  3.1 … 3.n（一节一个对比轴）
4 结果与讨论
  4.1 … 4.n（结构/条件/机理/误差）
5 思考题
6 结论
参考文献（只列真正引用的）
附录（数据文件选择、补充图、脚本说明）
```

### 1.1 篇幅预算（以 3000–5000 字课程报告为例）

| 部分 | 建议篇幅 | 重点 |
|---|---:|---|
| 引言 | 300–500 字 | 问题、方法能测什么、本报告范围 |
| 目的 | 150–250 字 | 可检查的目标，不写“了解”空话 |
| 原理 | 500–800 字 | 公式、符号、适用条件、与本次测量的关系 |
| 步骤 | 400–600 字 | 操作 + 目的 + 关键条件 |
| 结果 | 800–1200 字 | 图/表 + 数值 + 归属/比较 |
| 讨论 | 600–900 字 | 机理两环 + 误差四要素 + 边界 |
| 思考题 | 400–700 字 | 逐题、联系本次数据 |
| 结论 | 200–350 字 | 目的—数值—限制 |

字数不是目标；每段是否推进论证才是。

## 2. 逐节起草法

### 2.1 实验目的：写成“可检查的目标”

不要写：

> 了解红外光谱的原理，掌握红外光谱仪的使用方法。

改写为：

> 用 FTIR 测定 PE、PP、PS、PVA、PAN 与一只未知手套的透射谱；以基团区与指纹区的峰位差异鉴别五种塑料，并用峰位偏差、全谱相似度和缺失特征带三条证据判断手套的高分子种类。

规则：

- 每条目的都有一个动词（测定/比较/鉴别/计算/验证）和一个对象；
- 目的与结论一一对应；目的里没写的，结论不要突然出现；
- 3–5 条即可，不要抄讲义。

### 2.2 实验原理：三段，不要教科书大段

```text
第1段：方法测什么 → 物理量 → 与样品性质的关系
第2段：核心公式/模型 → 符号与单位 → 适用条件与假设
第3段：由公式到本次数据处理（拟合/积分/标定/归属）
```

规则：

- 每个公式首次出现解释符号；单位用正体；
- 只保留与本次结果解释有关的原理；删掉仪器发展史；
- 写清“这个公式在什么范围内成立”，为后面的边界句埋笔；
- 如果原理里有近似（如光程、基线、相对法），在这里写明。

### 2.3 实验步骤：操作 + 目的 + 关键条件

不要写软件点击流水账。每条步骤至少包含：

```text
做什么 → 为什么这样做 → 关键条件/参数
```

示例：

> 先采集纯 KBr 压片的背景谱，再测样品；这样扣除空气中水汽、CO₂ 与仪器本底，避免把背景吸收当成样品峰。所有谱图均在 500–4000 cm⁻¹、2 cm⁻¹ 分辨率、累加 16 次下采集。

规则：

- 按实际顺序编号；
- 只写影响结果的操作；无关外观删掉；
- 未记录的条件写“未记录”，不要补默认值；
- 与讲义不同的操作，写明“本组实际为……”。

### 2.4 数据与结果：图/表先行，一节一个对比轴

先做图/表，再写正文。图从哪来见 `05_Tools/FIGURES.md`：优先 Origin/Excel 导出 PNG；AI 无绘图库时交数据+`plot_spec.md`，不要伪造图。每个结果节按“5 句法”：

```text
① 图/表定位：由图 N / 表 N 可见……
② 主现象：在……处出现…… / 随……变化……
③ 关键数值：峰位、积分、强度、R²、J、ΔH、Mn 等（带单位）
④ 归属/比较：与……对应；与……相比高/低……
⑤ 一句限制：该结果能说明什么，不能说明什么
```

规则：

- 每个图/表在正文至少引用一次；图号/表号连续；
- 图注：图号 + 样品 + 条件 + 关键标注/单位；解释留给正文；
- 表注：单位在表头；排除点/缩写/来源在表下；
- 排除点保留在表中，标“是否纳入/原因”；
- 没有数值的判断，降级为“提示/可能”或补数据。

**起草时的“空位”写法**：如果某个数值还没算出来，写 `【待核：xxx】`，不要编一个数；交付前必须清零。

### 2.5 讨论：四句法 + 两环机理 + 四要素误差

```text
差异 → 结构/条件原因 → 机理两环 → 边界
```

机理至少两环：

```text
结构/条件 → 分子事件 → 可观测信号
```

例：

> PS 的叔碳/苄基氢易被夺取 → 生成共振稳定的苄基自由基 → 主链在较低温度开始断裂 → TGA 上表现为更低的 Td。

误差段四要素：

```text
来源（具体环节）→ 影响哪个参数 → 方向/量级 → 改进
```

不要写“人为误差/仪器误差”单独出现；不要把所有误差都归因于“操作不熟练”。

### 2.6 思考题：逐题回答，不抄讲义

每题按“定义—公式—本次条件—限制”回答：

```text
题目在问什么 → 定义/公式 → 本次数据/条件如何对应 → 不能回答什么/还需什么
```

规则：

- 一题一段或几段，不要合并成一大段；
- 能用本次数据就用；不能用的说明“本实验未测”；
- 不要复制讲义原文；用自己语言重述；
- 计算题给公式、代入、单位、结果。

### 2.7 结论：三层，不重复步骤

```text
① 回答目的：本实验用……测定了……，得到……
② 核心数值：3–6 个，带单位；必要时给范围/不确定度
③ 限制/下一步：主要误差、未记录条件、需要补做的实验
```

不要写“综上所述，本次实验非常成功”；不要新增结果。

## 3. 第一稿的句子规则

- 一句一个主张；超过 80 字拆开；
- 每个结论至少一个数（带单位），或明确写“定性观察”；
- 动词强度匹配证据：可见/显示 < 支持/一致 < 提示/可能 < 不能确定；
- 禁止：`证明`（除非排除其他解释）、`完全符合`、`必然`、`显然`、`众所周知`、`效果很好`、`可以看出来`；
- 数值与单位之间空一格：`109.0 ℃`、`57.9 J·g⁻¹`、`529 nm`；
- 范围用短横线：`0.5–10 μg·mL⁻¹`；负号用 `−`；
- 图注/表注数值与正文/表/Excel 一致；
- 未记录写“未记录/待核”，不补默认值。

## 4. 第一稿完成后的自检（进入四遍改稿前）

- [ ] 一句话问题能说清；
- [ ] 每个结果节有对比轴；
- [ ] 每个结论有数值/图/表/文献；
- [ ] 拟合/积分给了范围、n、R²/不确定度；
- [ ] 排除点有原因/反事实；
- [ ] 误差段有四要素；
- [ ] 结论三层，不超出证据；
- [ ] 标题写结论/问题，不写样品名；
- [ ] 图号/表号/正文/图注一致；
- [ ] 没有旧实验的样品名/数值/结论；
- [ ] 没有 `【待核】` 残留（提交版）。

## 5. 交给四遍改稿

第一稿不是终稿。按 `REVISION_WORKFLOW.md` 做四遍：

1. **论证遍**：问题、范围、对比轴、标题；
2. **证据遍**：证据矩阵、数值、反事实、未记录；
3. **段落遍**：5 句/4 句/四要素/三层；
4. **压缩遍**：删背景/流水账/重复表/无引用文献，保留数值/排除理由/不确定度/边界。

压缩遍不能省。旧版“写新报告只做 1–3 遍”已废止；本版 `README`、`REVISION_WORKFLOW` 已统一为四遍。

## 6. AI 与学生的分工

- AI 可以：整理数据、计算、绘图、起草、排版、检查、提出修改建议；
- 学生必须：判断峰/转变归属、确认结论、改写关键段落、署名；
- 课程禁止完全 AI 写作；AI 产出是“待学生确认的草稿”，不是提交版；
- 具体边界见 `01_Governance/HUMAN_IN_THE_LOOP.md`。

# 工作流：从初稿到终稿的改稿（REVISION_WORKFLOW）

版本：1.2（2026-10-26）
适用：AI 生成的实验报告初稿、自己写的初稿、旧版报告升级。
目标：不是“润色”，而是把“数据报告”改造成“有论点、有证据、有边界”的课程报告。
配套：`01_Governance/STYLE_PROFILE.md`、`04_Examples/STYLE_EVOLUTION.md`；没有初稿时先走 `02_Workflows/FIRST_DRAFT.md`。

## 0. 先立三条规矩

1. **有初稿才不要从零重写**：先做“改稿计划”，再逐段改；保留初稿中更严谨的证据。没有初稿，先用 `FIRST_DRAFT.md` 起草，再回到这里做四遍。
2. **先改论证，后改句子**：问题/范围/对比轴没定，换同义词没用。
3. **压缩不等于删证据**：删背景/流水账/重复；保留数值、排除理由、不确定度、对照。

## 1. 四遍改稿法

### 第一遍：论证与范围（Argument Pass）

目标：让报告有一个能回答的问题，而不是“把测过的都写上”。

操作：

1. 用一句话写出研究问题：
   ```text
   本实验要回答：在______条件下，______样品的______性质如何？与______相比有什么差异？为什么？
   ```
2. 列出所有样品/条件/数据文件，逐个问：
   - 它回答上述问题的哪一部分？
   - 删掉它，结论会缺什么？
   - 答不上来 → 先问用户能不能删；课程要求/用户要求优先；确认后再删除或降为“附注”。不要擅自删掉实际测过的样品。
3. 为每个结果节选一条**对比轴**：
   - 前/后（第一次 vs 第二次升温）
   - A/B（PE vs PET；邻/对苯二胺；A/B 未知物）
   - 条件 1/2（450 vs 520 nm 激发；DMSO vs D₂O）
   - 线性区/超范围（0.5–10 vs 35 μg·mL⁻¹）
   - 已知/未知（5 个塑料 vs 手套）
4. 把节标题改成“结论/问题”，不要写样品名：
   - `4.1 罗丹明试剂` → `4.1 罗丹明线性范围和高浓度偏离`
   - `4.2 对氨基苯甲酸` → `4.2 对氨基苯甲酸重复性`
   - `4.3 氧化锌` → `4.3 氧化锌样品的散射和饱和`
5. 删除没有证据的“应用前景/效果很好/是良好的……”句子。

产出：一张“范围表”：

| 样品/条件 | 回答的问题 | 对比对象 | 保留/删除 | 理由 |
|---|---|---|---|---|

### 第二遍：证据与数值（Evidence Pass）

目标：每个结论都能追到一个数/一张图/一条文献。

操作：

1. 建证据矩阵：

   | 结论 | 数据/图 | 关键数值 | 单位 | 对照/反事实 | 证据强度 |
   |---|---|---|---|---|---|
   | 罗丹明线性 | 图2/表2 | R²=0.99991；残差≤0.0085 | — | 纳入35后R²=0.95513 | 强 |
   | PET Tg≈79 ℃ | 图4 | 79.0/79.1 | ℃ | 基线窗口±3 ℃ | 中 |
   | 手套=PE型 | 图6/表6 | 峰位偏差≤1 cm⁻¹；r=0.985/0.970 | — | 与PP r=0.729/0.257 | 强 |

2. 每个关键结论补一个“质量指标”：
   - 拟合：R²、参数±标准误、n、残差；
   - 积分：积分区间、基线、复核值；
   - 谱图：δ、多重性、J、积分 H；
   - 热分析：峰温、ΔH、Xc、基线窗口；
   - GPC：Mn/Mw/Mz/d、积分区间；
   - 图像：比例尺、测量线、像素换算。
3. 对每个排除点做反事实：
   ```text
   若把______纳入，______指标从______变为______，因此排除/单独讨论。
   ```
4. 把“若……则……”改成实测：
   - 初稿：`若谱图信号集中于芳香区且积分约9H，则与9-蒽硼酸一致。`
   - 终稿：`由图6可见，δ 8.83（1.00H）、8.55（1.75H）、8.05（3.65H）、7.53（4.30H），合计10.70H；9个芳氢+未分辨的B(OH)₂宽峰……`
5. 未记录的条件写“未记录/待核”，不补默认值。

### 第三遍：段落与句子（Paragraph Pass）

目标：让每段只承担一个论证任务。

操作：

1. 结果段用“5 句法”：
   ```text
   图/表定位 → 主现象 → 关键数值 → 归属/比较 → 一句限制
   ```
2. 讨论段用“4 句法”：
   ```text
   差异 → 结构/条件原因 → 机理两环 → 边界
   ```
3. 误差段用“四要素”：
   ```text
   来源 → 影响哪个参数 → 方向/量级 → 改进
   ```
4. 结论用“三层”：
   ```text
   回答目的 → 3–6 个核心数值 → 限制/下一步
   ```
5. 句子检查：
   - 一句一个主张；超过 80 字拆开；
   - 动词强度匹配证据（见 STYLE_PROFILE 3.1）；
   - 删 `可以看出来/效果很好/基本没问题/证明/必然`；
   - 数值与单位之间空一格；范围用短横线；负号用 `−`；
   - 图注/表注与正文数值一致。
6. 读一遍：如果一段里出现“然后/接着/再”超过两次，多半是操作流水账，改成“目的—操作—原因”。

### 第四遍：压缩与体裁（Compression Pass）

目标：让报告像“课程报告”，不是“论文草稿/数据dump”。

操作：

1. 按优先级删（**样品/结论先问用户；课程/用户要求优先**）：
   - 与任务无关且用户同意删的样品/结论；
   - 软件点击步骤、仪器历史、教科书大段；
   - 重复表格/重复段落；
   - 无正文引用的文献；
   - 没有证据的“应用前景”。

> 样品不是“背景材料”。不确定时降为附注/附录，不要擅自删掉实际测过的样品。
2. 表格合并：
   - 一张表只承担一个比较任务；
   - 条件表 + 结果表通常足够；不要把每个样品拆一张表；
   - 峰归属表可以保留，因为读者需要横向比较。
3. 摘要/附录：
   - 课程模板不要求摘要时，可删；如果保留，摘要必须含“目的—方法—关键数值—排除/限制”，不要写成引言缩写。
   - 附录用于数据文件选择、补充图表、脚本说明；不要把正文该说的都塞附录。
4. 字数不是目标：
   - UV 终稿比初稿长 33%，因为增加了摘要/溯源/残差；
   - DSC/IR 终稿比初稿短 37%/47%，因为删掉了非课程必需内容；
   - 判断标准是“每段是否推进论证”，不是字数。
5. 压缩时保留：
   - 不确定度/敏感性/范围；
   - 排除理由；
   - 对照/反事实；
   - 方法限制。
6. 最后做“反向检查”：把终稿的每个小节标题连起来读，应该是一篇论证提纲；如果连不起来，说明结构没改好。

## 3. 逐段改写法（diff 思维）

不要整篇重写；按“段”做 diff：

| 初稿段落 | 问题类型 | 改法 | 终稿段落 |
|---|---|---|---|
| 4.1 罗丹明试剂 | 标题是样品名；只给R² | 标题写结论；补残差/反事实 | 4.1 罗丹明线性范围和高浓度偏离 |
| 4.2 对氨基苯甲酸 | 只描述两次不同 | 加“峰位差=一个采样间隔”与基线原因 | 4.2 对氨基苯甲酸重复性 |
| 4.3 氧化锌 | 只说A=10 | 说明截顶不是真实吸光度；不能算带隙 | 4.3 氧化锌样品的散射和饱和 |
| NMR 3.3 | “若……则……” | 换成实测峰组/积分/机理 | 3.3 未知样品B的鉴别与溶剂对比 |
| DSC 4.1 | 罗列两次结果 | 写“采用第二次”的决策与理由 | 4.1 热历史对样品熔融与结晶行为的影响 |
| IR 4.1 | 逐样品报峰 | 加“为什么指纹区更特异”的方法论 | 4.1 结构鉴别方式 |

## 4. 常见“假改稿”

| 假改稿 | 为什么没用 | 正确做法 |
|---|---|---|
| 只换同义词 | 论证结构没变 | 先改范围/对比轴/证据 |
| 只调格式 | 读者仍不知道重点 | 标题写结论；段落一句一任务 |
| 把所有数据都塞进附录 | 正文没有证据 | 关键数值留在正文，细节放附录 |
| 只加“可能/推测” | 证据不足被措辞掩盖 | 补数据或降级结论；不要用模糊词代替证据 |
| 把初稿删短 | 可能删掉不确定度 | 删背景/重复，保留证据/边界 |
| 让 AI 整篇重写 | 容易丢初稿的好句子/数值 | 先出 diff 计划，逐段替换 |

## 5. 交付前 11 项检查

- [ ] 一句话问题能说清。
- [ ] 每个结果节有对比轴。
- [ ] 每个结论有数值/图/文献。
- [ ] 拟合/积分给范围、n、R²/不确定度。
- [ ] 排除点有反事实或原因。
- [ ] 误差段有“来源→参数→方向/量级→改进”。
- [ ] 结论有三层，且不超出证据。
- [ ] 标题写结论/问题，不写样品名。
- [ ] 图号/表号/正文/图注/Excel 一致。
- [ ] 所有数据表为标准三线表（顶/底 1.5 pt、表头线 0.75 pt、无竖线/内横线）。
- [ ] 没有“证明/完全符合/人为误差/可以看出来”。

## 6. 与其他工作流的关系

- 写新报告：`EXPERIMENT_REPORT.md` 第 1–10 步 → `FIRST_DRAFT.md` 起草 → 本文件**四遍**（论证/证据/段落/压缩）→ 生成 DOCX/验收。
- 只改已有报告：本文件第 1–4 遍；不要重跑数据，除非证据有问题。
- 盲测：`06_Evaluation/BLIND_TEST_PLAN.md`；用本文件的“改稿计划”记录差异。

> 旧版“写新报告只做 1–3 遍”已废止；四遍都要做，尤其是压缩遍。

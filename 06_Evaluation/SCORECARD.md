# 评分表（SCORECARD）

版本：1.2（2026-10-26）
**定位：交付完整性/盲测评分，不衡量写作高明程度。** 写作风格看 `01_Governance/STYLE_PROFILE.md`；初稿→终稿的动作看 `04_Examples/STYLE_EVOLUTION.md`；从零起草看 `02_Workflows/FIRST_DRAFT.md`。
用途：盲测、交付验收、范例分级。评分不是课程分数，而是判断“能否交付/哪里要改”。

## 1. 两个门槛（先过门槛，再打分）

### 门槛 A：诚信与合规

出现任一情况，直接 **不合格**，不再看总分：

- [ ] 编造数据、实验条件、现象、文献、DOI；
- [ ] 伪造“已运行/已渲染/已验证”；
- [ ] 删除不利结果、篡改原始数据/图像；
- [ ] 抄袭或把 AI 整篇生成当作个人报告；
- [ ] 封面缺班级/姓名/学号/实验内容（本课程规定记 0 分）；
- [ ] 未按课程要求声明 AI 使用（如要求声明）；
- [ ] 把旧范例的高特征数值/样品名直接搬进新报告，且不能说明来源；
- [ ] 学生未阅读/未改写关键段落，却把整篇 AI 生成稿当作个人报告。

### 门槛 B：文件可用

- [ ] DOCX 能打开，无“文件已损坏”；
- [ ] PDF 能打开且来自最终 DOCX；未导出则标“未渲染”，不得标“已验收”；
- [ ] XLSX 能打开，无 `#REF!`/`#VALUE!`；
- [ ] 图/表编号连续，正文引用存在；
- [ ] 交付说明中的文件清单与实际一致；
- [ ] 旧范例数值污染检查已跑并逐条确认；
- [ ] 学生贡献记录已填。

门槛 B 任一项失败 → “待修”，不得标记“可提交”。

## 2. 七个维度（每项 1–5 分）

### 2.1 科学准确性

| 分 | 描述 |
|---|---|
| 5 | 概念、公式、单位、机理正确；结论不超出数据；区分观察/计算/文献/推测 |
| 4 | 基本正确，个别措辞过强或解释不完整 |
| 3 | 有明显不严谨（如把相关当因果、把推测当结论），但不影响主要结果 |
| 2 | 多处概念/机理解释错误，或结论明显超出证据 |
| 1 | 科学性错误贯穿全文 |

### 2.2 数据与计算正确性

| 分 | 描述 |
|---|---|
| 5 | 数据链完整；单位/有效数字正确；拟合/积分可复现；至少一种独立复核；排除点有记录 |
| 4 | 主要计算正确，少量细节（有效数字、表注）需修 |
| 3 | 结果大致可信，但缺复核或排除规则不清 |
| 2 | 关键数值/单位/拟合范围有错 |
| 1 | 数据错位、计算不可复现 |

### 2.3 论证逻辑

| 分 | 描述 |
|---|---|
| 5 | 问题—证据—解释—限制闭环；比较有对照；不循环论证 |
| 4 | 结构清楚，个别段落跳跃 |
| 3 | 有结构但像流水账；讨论与结果重复 |
| 2 | 结论与证据脱节；段落无序 |
| 1 | 无论证，只堆文字 |

### 2.4 写作风格匹配度

| 分 | 描述 |
|---|---|
| 5 | 符合 `STYLE_PROFILE.md`：正式、克制、定量、事实分层；像本人稳定表达 |
| 4 | 基本符合，偶有口语/长句/模板腔 |
| 3 | 正确但泛化；缺个人判断；误差分析空泛 |
| 2 | 明显 AI 腔/教科书摘抄/绝对化 |
| 1 | 口语化或无法提交 |

### 2.5 格式与模板匹配度

| 分 | 描述 |
|---|---|
| 5 | 页面、字体、字号、行距、标题、图注、三线表、公式、页码全部符合规范 |
| 4 | 主要项符合，少量偏差（如个别标题字号） |
| 3 | 能读，但字体/表格/图注/编号有明显不统一 |
| 2 | 版式混乱，影响阅读 |
| 1 | 未按模板 |

### 2.6 来源可追溯性

| 分 | 描述 |
|---|---|
| 5 | 每个结论能追到原始文件/列/脚本/图表；排除点有原因；引用真实可查 |
| 4 | 主要结果可追，少量缺文件/列说明 |
| 3 | 只能追到汇总表，原始数据/脚本不全 |
| 2 | 多数数值无来源 |
| 1 | 无法追溯 |

### 2.7 文件完整性与可编辑性

| 分 | 描述 |
|---|---|
| 5 | DOCX/PDF/XLSX/Origin/图源/脚本/交付说明齐全；图表原生可编辑；命名清晰 |
| 4 | 缺 1 项非关键文件，或个别图是位图 |
| 3 | 缺 XLSX/PDF/图源之一；交付说明与实际有出入 |
| 2 | 只有 DOCX 或只有图片；不可编辑 |
| 1 | 文件打不开/缺主要交付 |

## 3. 总分与等级

| 总分（/35） | 等级 | 处理 |
|---|---|---|
| 29.0–35 | Gold 候选 | 可作长期范例；仍需过门槛 A/B |
| 24.0–28.9 | Silver | 可选段模仿；先修已知问题 |
| 20.0–23.9 | Reference | 只取某个方法/事实/版式 |
| <20 | 不可用 | 重做或大修 |

注意：

- **总分不能抵消门槛 A**；造假直接不合格。
- 格式高分不能抵消数据错误。
- 等级不完全等于总分：某报告内容可作 Gold、版式可作反例，需在范例卡中写明“可学/不可学”。
- 课程合规（封面）是独立阻断项，不进入 35 分。

## 5. 从差异到规则

每次评分后，把扣分点转成可执行规则：

| 扣分点 | 规则 | 写入 |
|---|---|---|
| 图注数值与表不一致 | 图注纳入核对表，逐项比对 | `EXPERIMENT_REPORT.md` 第 7 步 |
| 字体回退 | 三层显式 + XML 审计 | `FORMAT_PROFILE.md` 2.2 |
| 封面缺失 | 生成前填字段，渲染后查首页 | `FORMAT_PROFILE.md` 3 |
| 结论超出证据 | 结论逐句对照证据矩阵 | `SCIENTIFIC_INTEGRITY.md` 3 |
| 交付说明页数错 | 页数由最终文件统计 | `DELIVERY_NOTE.md` |

规则必须可检查、可复现；不要写“写得更专业”。

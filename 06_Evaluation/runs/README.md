# 盲测运行记录（runs/）

每个盲测任务一个目录：

```text
runs/<日期>_<任务>/
  input/             # 只读：讲义、数据、模板、封面（不含终稿）
  output/            # AI 产出：MD/DOCX/图/表/交付说明
  score.md           # 按 SCORECARD 打分
  diff.md            # 与隐藏终稿的差异（结构/数值/图表/语言/格式）
  notes.md           # 归因与规则修改
```

## 规则

- 输入包不含终稿；评分人保管终稿。
- 先过门槛 A（诚信/合规）与门槛 B（文件可用），再看 7 维。
- 记录模型/版本、日期、使用的规范版本（本包 VERSION）。
- 未通过比通过更有价值；不要美化。
- 每次只改 1–3 条规则，再复测。

## 首轮建议

- 任务：TGA 或 GPC（数据链完整、差异大）。
- 通过线：≥26/35 且无 P0 阻断。
- 产出必须能打开；PDF 未导出则标“未渲染”，不得标“已验收”。
